# UI copy style

## Rules

- Headings and button labels use sentence case ("Create project", never "Create Project").
- No trailing period or exclamation mark in headings, buttons, labels or toasts.
- An empty state has a short heading plus one sentence saying what to do next, for example the heading "No projects yet" and the line "Create your first project to get started."
- Error copy never says "Oops" or "Whoops"; it says what happened and what to do.
- All copy lives in `src/copy/en.json`. Components read it through `t("key")`. Never hard-code a user-visible string in a component.
