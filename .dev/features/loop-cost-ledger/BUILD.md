## The floor caught a real defect mid-build — three times, in the same shape

The plan declared two **bare directories** in `## Files`. `set-writes-scope.cjs` resolves **concrete
paths**, so a trailing-slash entry authorizes nothing inside it:

1. `architecture-patch/` — the `APPLY.md` **Write was denied** by the fix #7 hook.
2. `README.md`'s shields badge — `check:badge` **REDded**; the badge sits OUTSIDE the generated
   `CURRENT-STATE` markers, so the "regenerated by `docs:generate`" entry did not cover it.
3. `fixtures/cost-ledger/with-subagents/` — `check-bash-reconcile` returned **ESCAPE** naming all three
   files with `denied_by: "writes-scope (snapshot)"`, because a generator wrote them through Bash where
   no `PreToolUse` guard sees them. `single-session.jsonl`, a **concrete** entry written the same way, did
   **not** escape — the controlled comparison that identifies the cause.

Each was fixed the prescribed way — **declare the concrete path in `## Files`, re-run the setter, amend
the open epoch** — never by widening scope ad hoc, never by a Bash write around the hook, and **never by
hand-editing the baseline**, which would silence the detector rather than answer it. Three amendments are
recorded on the epoch. All three corrections are written into the PLAN where they happened, not smoothed
over.

**(2) is this plan's own L49 point demonstrated on itself:** the meta-doc sweep NAMED the badge as
checker-backed and the `## Files` list still failed to make it writable. It was caught because that one
site happens to have a checker. The sites the sweep listed as **not** checker-backed — the `CLAUDE.md`
entries, the contract's prose, every honest-bound header — would have shipped stale in silence.

## Honest bounds carried into the artifacts, not just the plan (L2)

Each ships **in the file it describes**, because the PLAN is ephemeral and these are durable: coverage has
no `complete` member; the ledger records **tokens** and embeds no price table, ever; `output_thinking` is
a **subset** of `output`; "no message content, no home paths" is a **consequence** of the three rules, not
a detector, and **"no usernames" is struck** because no regex proves it; the checker certifies **internal
consistency**, never that `requests[]` matches the transcript — with a test that **fabricates a
self-consistent ledger** and shows it passes, then shows `--verify-transcript` catching it; and the
measured **~393 KiB** per run is stated in the contract, the emitter header and `CLAUDE.md` so a reader
meets it before a diff does.

The ledger **annotates and gates nothing** (fix #3): `check-cost-ledger.mjs`'s exit code is not a
proceed/stop input, and the Step 6c commit stays gated on `STOP_GREEN` ∧ the decision re-derivation.
